# ASCII-конспект схем конструкторского раздела

Ниже приведены ASCII-версии всех схем конструкторского раздела, начиная с подраздела «Вспомогательные функции». Они составлены напрямую по исходникам из `report/figures/*.dot`.

## 1. Вспомогательные функции

Источник: `report/figures/design_support_functions.dot`

### 1.1. Функция `set_updated_at`

```text
[Срабатывание BEFORE UPDATE]
            |
            v
[Присвоить NEW.updated_at = NOW()]
            |
            v
        [Вернуть NEW]
```

### 1.2. Функция `has_role`

```text
[Начало]
   |
   v
[Проверить наличие записи в user_roles
 с нужным code роли]
   |
   v
[Вернуть true / false]
```

### 1.3. Функция `get_service_price`

```text
[Начало]
   |
   v
[Выбрать актуальную цену
 для услуги на момент времени]
   |
   v
<Цена найдена?>
   | да                 | нет
   v                    v
[Вернуть цену]   [Сгенерировать ошибку
                   о неактивной цене]
```
