# Медицинская клиника

Курсовой проект по базам данных, ИУ7, МГТУ им. Н. Э. Баумана.

Регистрация пациентов, расписание врачей, запись на приём, результаты посещений и оплата услуг.

- `backend` — API на Go.
- `frontend` — интерфейс на React и TypeScript.
- `db` — схема PostgreSQL, функции, триггеры и тестовые данные.
- `report` — исходники расчётно-пояснительной записки.
- `diagrams` — схемы и диаграммы.
- `deliverables` — отчёт и презентация.
